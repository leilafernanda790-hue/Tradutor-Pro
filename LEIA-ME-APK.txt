TRADUTOR PRO — PROJETO ANDROID PARA GERAR APK

Este pacote contém o app de estudos dentro de um aplicativo Android nativo simples (WebView).
IMPORTANTE: este ambiente não tem Android SDK/Gradle instalado, então não foi possível compilar
um arquivo .apk aqui. O projeto está preparado para gerar um APK debug automaticamente no GitHub.

COMO GERAR O APK PELO GITHUB (sem instalar ferramentas no computador):
1. Entre em https://github.com e crie um repositório novo, por exemplo "tradutor-pro".
2. Envie TODOS os arquivos e pastas deste ZIP para o repositório (incluindo a pasta oculta .github).
3. Abra a aba "Actions".
4. Se solicitado, habilite os workflows.
5. Abra "Build Tradutor Pro APK" e clique em "Run workflow" (ou aguarde o build após enviar arquivos).
6. Quando terminar com sucesso, abra a execução e baixe o artefato "Tradutor-Pro-APK".
7. Extraia o ZIP baixado: o arquivo será app-debug.apk.
8. Envie o APK ao celular Android e abra-o. Se o Android bloquear, permita "Instalar apps desconhecidos"
   para o aplicativo usado para abrir o arquivo.

O APK gerado é uma versão de teste/debug, adequada para instalar manualmente; não é uma versão publicada
na Play Store. O app usa conteúdo local e mantém o progresso no armazenamento local do WebView.

REQUISITOS DO BUILD: Java 17, Gradle 8.9 e Android SDK platform/build-tools 35 (o workflow configura isso).
